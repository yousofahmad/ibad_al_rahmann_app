# تقويم هجري مصري رسمي

الأداة `tools/sync_egyptian_hijri.py` تجلب جدول **القاهرة** من [الهيئة المصرية العامة للمساحة](https://www.esa.gov.eg/monthlymwaket.aspx) عبر GET ثم ASP.NET form POST مستقل لكل شهر. قيمة المدينة تُقرأ من `select` الحي (وتتضمن أحياناً علامة تطويل عربية)، ولا تُحسب أي تواريخ محلياً.

```bash
python3 tools/sync_egyptian_hijri.py
# أو تحديث شهر/أشهر محددة: --months 1,2,12 أو --months 1-12
python3 -m pip install -r tools/requirements.txt
python3 -m unittest discover -s test -p 'test_sync_egyptian_hijri.py'
```

يُكتب `assets/data/egyptian_hijri_calendar.json` بواجهة `schemaVersion: 1`، وخريطة `dates` مفاتيحها ميلادية وقيمها `{day,month,year}` هجرية. يُستخرج العام الميلادي من كل سجل منشور؛ لا يُفترض من وسيط أو من تاريخ التشغيل. قبل الكتابة تتحقق الأداة من وجود GridView، صحة `datetime.date` (وبالتالي رفض 30 فبراير)، صحة السنة الهجرية، وعدم أي تكرار حتى لو كان السجلان متطابقين. يجب أن يحتوي كل جدول القاهرة على سنة/شهر ميلادي واحد وكل أيام الشهر كاملة وفق `calendar.monthrange`. الكتابة ذرّية، والبيانات القديمة تُدمج ولا تُمسح عند تحديث جزئي.

لتثبيت الاعتمادات قبل التشغيل استخدم `python3 -m pip install -r tools/requirements.txt`؛ وتشمل `requests` و`beautifulsoup4`. التطبيق لا يجلب أو يحدّث بيانات المستقبل تلقائياً: بعد نشر سنة جديدة أعد تشغيل الأداة (كلياً أو للأشهر المطلوبة) ثم أصدر ملف JSON الناتج مع إصدار التطبيق.

## النطاق والقيود

- لا تُضاف إلا سجلات ظهرت فعلاً في HTML الهيئة. عدم توفر شهر أو فشل postback يوقف التحديث قبل الكتابة، فيبقى الملف السابق سليماً.
- `coverage.fetchedMonths` يوضح الأشهر التي جُلبت في العملية الأخيرة، و`gregorianYears` و`recordCount` يصفان كل البيانات المتراكمة. الجداول المستقبلية لا تعني اعتماد سنوات مستقبلية: ما لا تنشره الهيئة لا يُنشأ بالحساب.
- صفحة `daily.html` المحفوظة استُخدمت لفهم بنية GridView، و`monthly.html` لفهم عناصر ASP.NET. مصدر البيانات النهائي هو الاستجابة الحية للهيئة.
- واجهة دار الإفتاء الاختيارية `http://di107.dar-alifta.org/api/HijriDate?langID=1` لم تكن متاحة أثناء التنفيذ (الاتصال أُغلق؛ وHTTPS لديه مشكلة SSL). عدم توفرها لا يعطل مصدر الهيئة ولا يجعلها بديلاً عنه.
